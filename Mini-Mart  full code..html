About LocalMart

LocalMart is a frontend-based e-commerce prototype designed for connecting local shops with nearby customers.

The main purpose of this project is to provide a simple online shopping interface for local businesses and customers.

This project demonstrates HTML5 and CSS3 concepts such as semantic structure, forms, navigation, Flexbox, Grid and responsive web design.
